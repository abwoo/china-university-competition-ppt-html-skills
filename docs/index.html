国内大学各项比赛 PPT 和 HTML skills

做两类东西的 skill：科技风 HTML 动画演示，和国内比赛套路式 PPT。

两条轨道

HTML ＝ 科技风

  • 单文件 HTML 动画演示，可录屏成视频
  • 深色底、蓝紫发光节点、青蓝连线
  • 粒子流动、Swarm 多光标
  • 起点：skill/assets/template.html

PPT ＝ 比赛风

  • 原生可编辑 PPTX（16:9）
  • 国内比赛套路式视觉：深蓝底、金色书法大标题
  • 白卡片、2×2 数字卡、章节标签、弧线光带
  • 先读：skill/references/competition-style-distilled.md
两条轨道不许混。HTML 里不出现金色书法大标题、白卡片；PPT 里不出现流动粒子、雷达、Swarm 光标。

PPT 轨道 · 比赛套路清单

封面三件套

左上赛事全称 + 右上 logo 占位；中央项目名书法体超大字；名下压一条口号；底部一行药丸标签（赛道 / 学校 / 组别 / 负责人）。先定“底色 + 金属点缀色 + 主视觉照片”三件，再套同一套章节与页型。

深蓝底色值抄准

官方模板实测主底色 #002B4B（左上），向右上渐亮至 #005389–#005B94，中部 #004370；封面、内容页、封底共用同一套底。

章节标题淡香槟金

短金横线 + “一、项目背景”（“一、”小字 + 节名大字），金色取样 #FFE7B0 / #FFE8B3 / #FFE1A0；封底巨字口号用更深更饱和的金 #F8D44F / #F3C53C。

内容页固定骨架

左上 NAVY 圆角 section 标签（2.6×0.6 英寸，NAVY 底白字 22pt Bold）＋“——副标题”16pt 灰＋右下角页码“X/总数”10pt；三栏卡片 / 左右分栏 / 时间线三种版式按内容选用。

数据与对比只用清单里的版式

黑底 + 青蓝图表数字标图上，或 2×2 白色数字卡、中央大数字 + 上升箭头、双柱对比条形图；对比页三选一（对比表 / 左右冷暖栏金色只给己方 / 相交大圆）；数字卡每页至少 3 个真实指标，不够就合页，不编数。

8 节顺序与页数上限按赛道版本抄死

省赛 / 青创北京版：背景 ≤2 / 整体 ≤2 / 核心技术 ≤4 / 商业模式 ≤3 / 项目应用 ≤4 / 社会价值 ≤1 / 团队 ≤1 / 未来展望 ≤1（合计 18 页）；合工大专项赛版把项目应用与商业模式对调，同一模板两个顺序，不能混用。

赛道换皮

科技蓝 #165DFF、乡村振兴草绿 #00B42A、文创暖橙 #FF7D00、公益暖红 #F53F3F；农业 / 乡村类用绿主色 + 实拍大图，别硬套深蓝。

目录结构

skill/   # skill 本体
  SKILL.md              # 主说明：视觉母版、双路线、双模式、硬规则
  references/           # 规则与调研：比赛套路提炼、真实案例拆解、风格 token、融合来源
  assets/               # HTML 模板、PPTX 模板
  scripts/              # check.py 自检、make_pptx.py 生成 PPTX
docs/    # 说明站（本页）

用法

  1. 做 HTML 动画演示：用 skill/assets/template.html 作起点，按 skill/SKILL.md 的视觉母版改；跑 skill/scripts/check.py 自检。
  2. 做比赛 PPT：先读 skill/references/competition-style-distilled.md 的套路清单，再按 skill/SKILL.md 的结构做；生成见 skill/scripts/make_pptx.py。
  3. 比赛结构硬约束（页数、章节顺序、标题即结论）优先于视觉套路。
