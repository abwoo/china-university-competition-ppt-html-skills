## 1. 构图质量契约（照搬，画任何图之前先打勾）

- 零交叉：边与边不交叉；实在避不开的交叉必须用桥跳（bridge jump）显式标出
- 每条边最多 2 个拐点，全图最多 8 个拐点
- 节点间距 ≥40px，容器边距 ≥20px
- 短正交线段优先，标签避让节点、连线、分区标题
- 标签不截断：文字过长时换行或缩短，不许让文字溢出节点、画布
- 输出前做结构验证：重复 ID、悬空引用、非法拐点、非有限几何值，一律在渲染前报错

## 3. 语义形状词表（照搬）

- LLM：双边框矩形
- Agent：六边形
- 向量库：带环圆柱体
- 服务/模块：矩形；数据存储：圆柱体；决策：菱形；事件/消息：平行四边形

## 4. 语义箭头系统（照搬）

颜色 + 虚线样式编码含义，图例必须画出来：

| 含义 | 样式 |
|---|---|
| 写 / 调用 | 实线 |
| 读 / 返回 | 虚线 |
| 异步 | 点线 |
| 循环 / 反馈 | 带环箭头 |

## 5. 图型清单（14 种）

UML 全套：类图、组件图、部署图、包图、复合结构图、对象图、用例图、
活动图、状态机图、时序图、通信图、时序图（Timing）、交互概览图、ER 图；
另加 AI/Agent 领域图：RAG、Agentic Search、Mem0 记忆架构、多 Agent 协作、
工具调用流。本 skill 的 MVP 先做其中 6 种原型（见 SKILL.md），其余按此清单扩展。

## 6. 动效时间线（照搬：5.75 秒 settled-flow）

- 0–3.75 秒：连线按语义顺序画出（先画线）
- 3.75–5.75 秒：拓扑定型后，数据继续流动 2 秒
- 115 帧 / 20fps / 960px GIF；静态回归基线用 1920px PNG
- tech-style 改编：HTML 演示用同一节奏——节点依次出现、连线随后绘制、
  终态保持流动 2 秒后循环或停住。

## 7. 验证回路（照搬）

```
提示词 → 图契约 → 语义 IR → 风格规格 → 路由规划 → SVG 构建
  → 结构验证 → PNG 回读检查 → 定向修订 → 交付 SVG + PNG
```

每轮只修验证指出的问题，不重画整图；导出 PNG 后必须肉眼检查
裁切、重叠、标签位置、路由回归，通过才交付。
