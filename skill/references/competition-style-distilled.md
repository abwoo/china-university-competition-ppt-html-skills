> 背景：用户 2026-11-10 20:21 明确“PP 的风格就是国内比赛那种套路式的视觉内容和比赛 PPT 的视觉风格”，20:22 再明确分工“HTML 要的是科技风，比赛 PPT 一定是要比赛风”。
> 结论：PPT v5 的方向是对的，问题是执行不到位、不够像真的获奖 deck。本文件就是把套路抄得更准、更细、更可执行。

## 0. 分工硬规则（先写死，再谈风格）

**两条并行的风格轨道，不许混。**

| 轨道 | 用途 | 视觉血统 | 绝对不许流入的东西 |
|---|---|---|---|
| **HTML / 网页动画轨道 = 纯科技风** | 单文件 HTML 动画、可录屏成视频 | Oxtron 视频、fireworks-tech-graph、mg-styles-15 22-hud、HyperFrames、Swarm 多光标 | 比赛 deck 的视觉：金色书法大标题、白卡片、绿/红套路配色、章节标签图、2×2 白卡片——一律不许流进 HTML |
| **PPT / 比赛 deck 轨道 = 国内比赛套路式视觉** | 互联网+、挑战杯、创青春、三创赛、黑客松答辩 PPT | 真实金奖 deck、官方模板、接单设计师的创赛套路（见第 1 节清单） | 科技风轨道的发光节点、流动粒子、雷达扫描、Swarm 光标——不许作为 PPT 的默认视觉；PPT 里只在封面/章节/架构页保留静态深色科技造型（挑战杯合规要求，见第 3 节） |

违反分工的判断标准：一眼能看出是哪条轨道。HTML 里出现金色书法大标题或白卡片，就是串轨；PPT 里出现流动粒子、雷达、Swarm 光标，就是串轨。

## 1. PPT 轨道套路清单：照着抄

> 读法：每条 = 长什么样 ＋ 出处（真实案例第几节/第几页） ＋ 什么情况下用 ＋ 数值（有就写，没有就写“未知，不猜”）。
> 这些套路不是要避免的东西，正是要抄准的东西。抄的是版式、配色逻辑、标题写法，不抄别人的项目内容与占位数字。

### 1A. 封面：三件套，12 个封面全是这个结构

**A1. 深色底 + 中央大号书法体标题 + 实拍拼贴图（金奖封面标准起手式）**

- 长什么样：深色底，中央一句白色大号书法字标题，下方一至两行定位副标题，左上放品牌标志，配实拍拼贴图。
- 出处：real-gold-cases.md §1 站酷 Bluebox（2020 年“互联网+”金奖，软体机器人湿式 3D 打印）封面——深色底 + 实拍拼贴图（柔性机械手抓番茄等），左上蓝色 Bluebox 标志，中央白色大号书法字“刚柔并进”，副标题“全球软体机器人湿式 3D 打印开拓者”“创意组「玄火君」”。§21-1 同案提炼：标题公式 = 一句四字书法大标题 + 一行定位副标题。
- 什么情况下用：互联网+、挑战杯路演封面默认用这一式；封面字要大、留白要多（real-gold-cases.md §8 规则 1）。
- 数值：书法字体名未知，不猜；字号按 domestic-competition-style.md §0 通用底线与 SKILL.md：标题 32–44pt（PPTX），封面可更大（深圳杯答辩 PPT 封面 54pt，real-gold-cases.md §22 规则 63；限定：那是深圳杯，不是国赛）。

**A2. 封面三件套固定死（TOUCHPPT 12 套全同款）**

- 长什么样：左上“第×届中国国际‘互联网+’大学生创新创业大赛”+ 右上 logo 占位；中央项目名书法体超大字（颜色按主题变）；名下压一条口号；底部一行药丸标签（赛道 / 学校 / 组别 / 负责人）。
- 出处：real-gold-cases.md §24（TOUCHPPT 剩余 110 张预览图全部看完，12 页 118 张图）提炼的 6 条之首；§31 规则 72 同款。
- 什么情况下用：任何互联网+封面，先套这三件套再换主题色与主视觉照片。
- 数值：无 hex、无字号记录，未知，不猜。

**A3. 深蓝渐变封面 + 渐变大标题 + 斜切亮蓝带（蓝色科技风封面式）**

- 长什么样：深蓝渐变底（左深右亮），顶部大赛 logo + 赛事全称，主标题超大字白→浅蓝渐变填充，上下配科技感细线框 + 节点圆点装饰，副标题白色粗体，左下四行信息（汇报人 / 赛道 / 组别 / 高校），底部一条斜切亮蓝带，右半幅一张项目实拍大图。
- 出处：real-gold-cases.md §16-1 TOUCHPPT 767.html（蓝色科技风互联网+创赛国奖 PPT 设计案例，2024-05-22，图 1 封面 1920×1080）；§22 规则 57 同款。注意：该页文字全是占位符（“项目名称”“输入文本”），只抄版式，不抄文字与数字。
- 什么情况下用：水产、硬件、科技类项目的蓝色科技风封面。
- 数值：渐变色值未知，不猜；右半幅实拍图必须是真实项目照片，不用占位图、不用 AI 图。

**A4. 赛道换皮封面：绿 / 金 / 棕金 / 深红，各有定式**

- 长什么样：底色 + 金属点缀色 + 主视觉照片三件先定，再套同一套章节与页型。
  - 智慧农业：深绿底 + 右上暖黄阳光光晕 + 白色→浅绿渐变书法大字 + 右半幅双手捧毛豆荚实拍 + 底部绿色光线 / 科技线条（§16-4，806.html；§22 规则 60）。
  - 非遗：深棕 / 古铜底 + 顶部金色光束 + 金色粒子 + 金色书法大字（金粉飞溅效果）+ 左下 2×2 胶囊信息条（深棕标签 + 米色底）+ 右下角棕金绸缎波纹 + 右半幅两只古陶罐实拍（§16-5，809.html；§22 规则 61）。
  - 国潮中国风：墨绿 / 深青底 + 金色书法大字带发光 + 红色印章 + 青绿山水插画（金线勾边山峦、飞鸟），副标题白字压金色笔触横条（§16-2，747.html“天工开物”；§22 规则 59）。
  - 红色公益：深红 + 金换皮，封面留守儿童照 + 红丝绸（§24，807.html）。
  - 矿难 / 深蓝 + 金：封面“矿难救星”金书法 + 矿井矿工照 + 蓝色心电图波形线（§24，748.html）。
- 出处：real-gold-cases.md §24 配色按赛道换皮、不换骨架；§31 规则 77 同款。
- 什么情况下用：先看赛道再定皮。农业 / 乡村类不要硬套深蓝科技风，绿主色 + 实拍大图才是评委熟悉的语言（§2 搜狐改稿案例可抄的点；§8 规则 4）。
- 数值：各皮 hex 均未知，不猜；只记“底色 + 金属点缀色 + 主视觉照片”三件。

**A5. 黑金封面：全黑底 + 金色书法 + 细金边框，三件套齐了就够**

- 长什么样：全黑底 + 金色书法 / 金色描边，中央圆形大图（金色六边形镜面 + 隧道内人物剪影），左右两侧金色细边框深色条块并列文字；背景分析页用黑底星空 + 城市天际线剪影 + 金色书法“关键词”，一页只讲一个词。
- 出处：real-gold-cases.md §5 站酷黑金科技感模板（2023-10-13，小目标 PPT）；§8 规则 5；§21-8 同案提炼。黑金分四种、别混用（极简黑金 / 质感黑金 / 大气黑金 / 立体黑金），见 §10G 规则 9（来源 iSlide、Canva 两篇解析一致，二手解析文章）。
- 什么情况下用：要“贵气”的科技感封面与“三大核心技术”页（中央圆形大图 + 左右条块并列是现成版式，§8 规则 8）。
- 数值：金色 hex 未知，不猜；颜色总数不超过 4 种（§8 规则 5）；不要再加第四种亮色。

**A6. 顶部小字放赛事全称，是固定写法，不要省**

- 长什么样：封面顶部一行小字写赛事全称，如“第九届中国国际‘互联网+’大学生创新创业大赛”“第十三届‘挑战杯’大学生创业计划竞赛”。
- 出处：real-gold-cases.md §3 B站挑战杯美化后封面顶部小字；§8 规则 6；§14-1 案例 12 封面顶端“第十三届‘挑战杯’大学生创业计划竞赛 | 跃幕 NiceSlide”。
- 数值：字号未知，不猜；只记位置固定在顶部、字要小、不抢标题。

### 1B. 章节与导航：让评委一眼知道讲到哪

**B1. 章节导航条：内页顶部 4 个药丸导航，当前章节高亮**

- 长什么样：内页顶部 4 个药丸导航（项目背景 / 产品技术 / 项目团队 / 商业模式），当前章节高亮；标题用“01.产业现状 + 英文小字 INDUSTRY STATUS QUO”数字 + 中文 + 英文三层。
- 出处：real-gold-cases.md §24；§31 规则 73。
- 什么情况下用：网评长版（30–45 页）与多章节 deck 的默认导航；路演短版页数少，可只保留数字 + 中文标题。
- 数值：导航文字与字号未知，不猜。

**B2. 章节标签页眉（国赛金奖级长 deck，二手）**

- 长什么样：每页固定页眉——左上深色圆角 Section 标签（如“核心技术”“痛点分析”）+ 副标题以“——”开头描述本页核心论点 + 右下角页码“X / 总数”。
- 出处：real-gold-cases.md §13F 规则 32、§21-14（规则 32 的版式骨架）。**二手转述**：来自 GitHub liu-1101B/competition-ppt-skill 的 SKILL.md 文字主张，其自称分析过 41 页冰雪经济 + 43 页低空经济两份模板，但仓库内 0 个 .pptx/.pdf 文件，模板本身未见（§17-2 核实、§22 规则 69）。引用时必须写“据该 skill 自述”，不能写成“金奖模板实测如此”。
- 配色（同为二手）：默认深海军蓝 NAVY #0A1628、深蓝 #0F1D35、金 GOLD #C9A84C、浅金 #E8D58C、标题与正文等线字体（§17-2）。
- 什么情况下用：20–43 页长 deck 才用这套页眉；15–20 页短版不要为页眉占地方。

**B3. “01 输入标题”斜切蓝条 + 顶部右侧 5 个圆角胶囊导航（TOUCHPPT 内容页式）**

- 长什么样：左上“01 输入标题”斜切蓝条；顶部右侧 5 个圆角胶囊导航标签（首个高亮蓝底白字，其余描边）；小标题蓝白渐变字 + 下方发光横线；关键词金黄色高亮；蓝色虚线框卡片 + 蓝色箭头项目符号。
- 出处：real-gold-cases.md §16-1 图 2 内容页；§22 规则 58。
- 数值：色值未知，不猜；只记“斜切蓝条 + 胶囊导航 + 发光横线”三件。

**B4. 顶部色条 + 底部页码（浅色路演风，合成示例）**

- 长什么样：白底，每页顶部一条主色细线、底部放“NN / 17”页码，标题 #111827、正文 #6B7280，只用一个主色。
- 出处：real-gold-cases.md §30 icgma/slide-skill 互联网+包实测（17 页，逐项打开验证）；§31 规则 83。**合成示例**：仓库 README 原文写明“所有项目、数据、人名均为虚构示例”，数字、奖项、人名一律不得当真；且该包是浅色紫调，与深色科技感路线完全不同，不能混用（§30 结论）。
- 什么情况下用：只在要做浅色路演版时借这套 chrome；深色比赛风 deck 不要用。

### 1C. 数据页与数字卡：数字直接标在图上，不另起段解释

**C1. 黑底 + 青蓝图表，数字标在图上**

- 长什么样：黑底，青蓝色柱状图 / 环形图 / 面积图，数字直接标在图上，不另起一段解释。
- 出处：real-gold-cases.md §1 Bluebox 数据页（标注“354 亿美元（2014-2020）”“232 / 59 亿美元”）；§8 规则 3；§21-1 同案。
- 什么情况下用：市场规模、行业数据页默认用这一式。
- 数值：青蓝色值未知，不猜。

**C2. 2×2 白色数字卡片 + 人物笑脸实拍 + 底部斜切色块**

- 长什么样：四个并列事实用 2×2 白色卡片排，一卡一句话，不堆小字；卡片旁配一张人物笑脸实拍，底部用斜切色块收边。
- 出处：real-gold-cases.md §14-1 案例 12（NiceSlide × 第十三届挑战杯，乡村振兴光伏项目）“项目成效”页；§14-3 规则 37。**数字警告**：本案大量数字为 123、1234、12345.6 等占位数字，不能当作真实数据引用，只学版式（§14-1）。
- 什么情况下用：项目成效、落地成果页；卡片里只放已核实的真实数字，没有真实数字就写“待补”留占位，不编数。
- 数值：卡片字号未知，不猜；正文字号下限见第 3 节（答辩场合 ≥18pt）。

**C3. 中央大数字 + 上升箭头，下方柱状图 + 趋势线做证据**

- 长什么样：全页最想让人记住的数字放中央、特大号，旁边配一个上升箭头；下面再放一张逐年升高的柱状图 + 趋势线做证据，副标题给第三方来源。
- 出处：real-gold-cases.md §14-2 案例 13（腾讯全球数字生态大会·城市峰会）“为什么要自主研发”页——中央大字“110 万台”配上升箭头，下方 2005—2019 年柱状图（纵轴 0—1,200,000，柱体由深蓝渐变为青色、逐年升高，另有上升趋势线），副标题“Gartner：腾讯云 IaaS 市场增速全球第一”；§14-3 规则 43。
- 什么情况下用：全场只想让人记住一个数字的那一页；数字必须是真实的、有来源的。
- 数值：柱体渐变“深蓝→青色”，色值未知，不猜。

**C4. 双柱对比条形图：亮色柱高于深蓝基线柱，数值标在柱上**

- 长什么样：对比时亮色柱（青色）高于深蓝基线柱，数值直接标在柱上，下标一句话说明比较口径；不要用饼图讲对比。
- 出处：real-gold-cases.md §14-2 案例 13“自研服务器”页（最大负载效能 50%、视频处理速度 40%、图形转码得分 35%、Web 页面 QPS 150%，下标“云服务器实例性能提升”）；§14-3 规则 42。
- 数值：青色、深蓝色值未知，不猜。

**C5. 大数字指标卡横排，每页至少 3 个指标，不够就别拆页**

- 长什么样：试点、壁垒、财务这类页不用段落，用“超大数字 + 一行小字说明”的卡片横排，卡片白底浅阴影、数字用主色。
- 出处：real-gold-cases.md §30 slide-skill 互联网+包实测；§31 规则 84。**合成示例**（见 B4 的定性），反面教材是该包第 5–6 页把一节硬拆两页、第 6 页只剩 1 个指标。
- 什么情况下用：试点数据、壁垒、财务页；凑不够 3 个真实指标就合回一页，不硬拆。

**C6. 市场规模用大圆圈：圆圈是结论，柱状图是证据**

- 长什么样：市场规模不画折线图，用一个蓝色大圆圈写“千亿级市场”四个字放左侧，右侧再配一张逐年上升的柱状图做证据。
- 出处：real-gold-cases.md §15-1 视频 1 新“净”界（BV1WF411s7f8，第六届互联网+金奖路演现场，真浏览器逐帧实看）“市场空间”页；§15-4 规则 52。
- 数值：柱状图 2017 年约 4457.96、2020 年约 8540.4，单位疑为亿元、末位数字模糊，谨慎引用（§15-1 原文标注）。

**C7. 证据页“扇形铺排 + 大数字”：证书不列表格**

- 长什么样：专利 / 论文 / 证书不列表格，扇形或斜向铺满半页，左上压两个金色大数字“XX 项 发明专利 / XX 项 专利申请受理”配月桂枝；团队成长页左侧金色麦穗 / 月桂环绕的“获奖荣誉”圆 + 2020–2024 年份列表。
- 出处：real-gold-cases.md §24；§31 规则 75。
- 数值：数字必须是真实的专利 / 论文数；TOUCHPPT 原页的 69.76%、12 篇、100/500/1000 均为占位 / 模板填充数，无法核实，不得引用（§24 提醒、§31 规则 86）。

### 1D. 对比页：表讲参数，照片和评价讲可信度

**D1. 对比表 + 实拍照片 + 用户评价**

- 长什么样：竞品对比用一张表（光效 / 散热 / 可靠性 / 指向性），表旁配一张实拍照片（战机）加一句用户评价；表讲参数，照片和评价讲可信度。
- 出处：real-gold-cases.md §15-2 视频 2 中科光芯（BV1Ak4y187L3，第七届互联网+高教组冠军项目）对比表页；§15-4 规则 54。
- 什么情况下用：竞品对比页默认用这一式；对比维度只比 3–5 个（SKILL.md 第四步对比原型）。

### 1H. 配色总则（PPT 轨道）

- 颜色总数不超过 3–4 种；主色占 60%–70%、辅助色 20%–30%、点缀色 5%–10%（domestic-competition-style.md §0 通用底线）。
- 全 PPT 字体不超过 2 种（231 原则：2 种字体、3 档字号、1 致风格）（同上）。
- 白底 + 深蓝标题 + 红色强调：白底为主，深蓝标题 + 蓝色色块，只用红色强调关键数字与结论（过滤率 99.9%、市场潜力巨大）；红字只出现在结论句和数字上，不铺成大面积色块（real-gold-cases.md §15-1 视频 1 整体风格；§15-4 规则 48）。
- 浅色双色克制：浅色底 + 一个主色 + 一个辅色（如白 / 浅灰底 + 生机绿主色 + 活力橙辅色），亮点词、副标题、图标只用辅色点一下，不铺第三色（§14-1 案例 12；§14-3 规则 35）。
- 深蓝底 + 青蓝渐变标题 + 底部弧线光带：深蓝 / 近黑底，标题与线条用青色—蓝色渐变，页面底部固定一条蓝紫—绿色弧线光带收边；每页右上放品牌、左上放会议标志，位置全套统一（§14-2 案例 13；§14-3 规则 41）。
- 国赛官方模板实证：深海军蓝 #002B4B 一带底 + 金色渐变标题条图片 + 白色正文 + 网格 / 节点 / 光线底图；封面标题为图片文字（白色粗体 + “挑战杯”书法体）；内容页顶部金色标题条图片 + 下方细金线；字体微软雅黑 24pt 加粗；全 11 页无动画、无切换（real-gold-cases.md §29 汇报模板 PPTX 实测；§31 规则 79）。
- 配色按赛道换皮、不换骨架：智慧农业深绿 + 金、非遗深棕 + 铜金、红色公益深红 + 金、乡村振兴翠绿 + 白、新能源黑 + 墨绿 + 金、蓝色科技风深蓝 + 亮蓝 + 黄字；先定“底色 + 金属点缀色 + 主视觉照片”三件，再套同一套章节与页型（§24；§31 规则 77）。
- 颜色编码要一致：一页里一个颜色只代表一个意思（§10G 规则 14，来源 Custos Nox 评审复盘，二手解析）。
- 深色底是风险选择：投影仪 <2000 流明不推荐深色底，2000–3500 流明可用（对比度 +20%、调暗房间），3500–5000 流明推荐，>5000 流明理想；深色底上字号要比平时大 15%–20%；务必到现场实测，备一份“投影灾难版”（对比度更高、字号 +2pt、图片提亮 10%）（domestic-competition-style.md §0）。

### 1M. 数模答辩骨架（与创赛 deck 分开，数模专用）

## 4. 两层冲突时，谁赢

1. **轨道分工赢过一切**：HTML 里出现比赛视觉、PPT 里出现科技风动画，都是串轨，先改回各自轨道，再谈好不好看。

3. **结构赢过视觉**：页数超上限、顺序调换、标题写成中性词时，先砍页、调顺序、改标题，再修配色与版式。
4. **真实证据赢过套路**：没有真实照片、真实数字、真实证书时，套路里的照片位、数字卡、大数字一律留空写“待补”，不编图、不编数、不拿占位数字当真。TOUCHPPT 的占位数字（69.76%、12 篇、100/500/1000）与 NiceSlide 案的 123、1234、12345.6 均为占位，不得引用（real-gold-cases.md §24 提醒、§14-1 数字警告）。
5. **真实案例赢过二手转述**：一条规则同时有亲眼见内页的案例与二手转述时，按亲眼见的版本抄；二手转述（competition-ppt-skill 的 41/43 页模板、slide-skill 的合成示例包）只能作结构对照，引用时必须标“二手”或“合成示例”。
