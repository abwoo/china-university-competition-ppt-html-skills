# 获奖 PPT 案例拆解（公开报道，只学结构与表达，不复制项目内容）

本文件拆解 5 个公开可查的获奖项目（另附 1 个仅核实奖项的项目）。
所有事实均来自公开新闻报道的转述，未复制任何项目的 PPT 内容、图片、文字。
各项目的实际页数无公开依据，凡提到页数均为"按路演短版 15–20 页 /
网评长版 30–45 页的通用做法推断"，不编造成该项目的实际页数。

## 1. 哪吒——全球首个"海空一体"跨域航行器平台

- 学校/奖项：上海交通大学，中国国际大学生创新大赛 2024 冠军，
  评审最高分 950 分；从全球 153 个国家和地区、5406 所学校、514 万个项目中夺冠。
- 团队/历程：20 余位博士/硕士，历时 8 年。
- 逻辑链：痛点（空气与海水密度差约 850 倍，无人机能飞不能游、
  无人艇能游不能飞，几米浪涌中无法起飞）→ 核心技术（首创"冲浪算法"，
  自主识别波浪、在波峰起飞，3 年攻关，一次起飞成功率提升至 86%）→
  性能数据（哪吒 IV 负载 7 公斤、飞行高度 1000 米、潜深 100 米；
  哪吒-海箭飞行高度 3000 米、时速 200 公里）→ 验证（3 级海况
  浪高 0.5–1.25 米下反复海空穿越，下潜突破 100 米）→ 应用
  （海洋监测、台风气象数据采集、资源勘探、海上搜救、抹香鲸生态跟踪）。
- 学到的表达：一个核心痛点 + 一张对比图（飞/游各缺一半）；
  核心技术独立成页，讲一个算法名 + 一个关键数字（86%）；
  性能数据用一张参数表，不堆文字；应用场景一页只放 3–5 个场景名。
- 封面/章节页：项目名 + 一句话价值主张（"海空一体"），封面配航行器实物图。

  - https://news.sciencenet.cn/htmlnews/2025/9/552460.shtm
  - https://www.shanghai.gov.cn/nw4411/20241015/1a114194ad5341f2afdfadedcd412618.html

## 2. 光联华夏——光子太赫兹无缝融合通信开拓者

- 学校/奖项：东南大学，第八届互联网+高教主赛道全国金奖；
  另获 2022 日内瓦国际发明展金奖。
- 依托：东南大学信息科学与工程学院与紫金山实验室。
- 逻辑链：痛点（5G 速率瓶颈）→ 核心技术（360–430GHz 频段、
  100/200Gbps 太赫兹无线实时传输，世界最高实时传输纪录，较 5G 提升 10–20 倍）→
  链路（"光纤-太赫兹-光纤"）→ 验证（发明展金奖等第三方背书）。
- 学到的表达：一个数字做钩子（"较 5G 提升 10–20 倍"）；
  频段与速率两个数字放同一页；第三方奖项单独一页做信任背书。
- 封面/章节页：项目名 + 速率数字，封面配实验室/设备图。
- 来源：
  - https://jiangsu.eol.cn/jsgd/202211/t20221124_2257487.shtml
  - 金奖案例视频（第八届金奖案例 04，省赛版路演视频）：
    https://www.bilibili.com/video/BV1io4y157rd/

## 3. 食菌速检——新一代食源性致病菌三模式快检仪

- 学校/奖项：中国石油大学（华东），中国国际大学生创新大赛 2025
  本科生创意组全国总决赛金奖。
- 团队：2021 级化工安全专业本科生任绪乾负责，曾景斌等 5 位老师指导；
  经校赛、省赛、国赛三级角逐夺冠。
- 逻辑链：痛点（食源性致病菌检测慢）→ 方案（三模式快检仪）→
  验证（校赛→省赛→国赛三级晋级本身就是验证链）。
- 学到的表达：本科生创意组金奖的叙事重点是"问题真实 + 方案可做"，
  不必堆营收；三级晋级经历可以写进研发历程时间线。
- 来源：https://cce.upc.edu.cn/2025/1016/c2641a473496/pagem.htm

## 4. 金优科技——全国农作物高效光合育种先行者

- 学校/奖项：浙江师范大学，第七届互联网+国家金奖 +
  "最佳带动就业奖"单项奖，小组第一参加三强排位赛。
- 指导人：陈析丰。
- 逻辑链：痛点（育种效率）→ 核心技术（高效光合育种）→
  社会价值（带动就业，获单项奖）→ 排位赛表现（小组第一）。
- 学到的表达：社会价值不要只写一句空话，要对应一个可核查的奖项或数字；
  有单项奖的项目，社会价值页单独成页。

## 5. 科技小院——科技精准服务乡村振兴的中国方案

- 学校/奖项：中国农业大学，中国国际大学生创新大赛金奖（红旅赛道）。
- 逻辑链：三大脱节（科技创新与生产需求、研究生培养与社会需求、
  科研人员与农民脱节）→ 模式（"政产学研用"五位一体综合服务平台、
  "赋智、赋值、赋权、赋能"四联动、"零距离、零门槛、零费用、零时差"四零服务）→
  演进（1.0 扎根脱贫攻坚 → 2.0 产业强农富民 → 3.0 服务乡村全面振兴 →
  2026 年进入 4.0 时代）→ 数据（全国 139 个科技小院；
  曲周王庄千亩方玉米亩产 849 公斤 + 小麦 661 公斤、周年亩产 1510 公斤、
  较常规增产 15%、氮肥增效 25%、节水 14%）。
- 学到的表达：模式类项目用"三段式口号"（五位一体/四联动/四零服务）
  压缩成一页，每段只给关键词；演进用时间线；数据页只放 5 个数字。
- 来源：
  - https://news.cau.edu.cn/zhxwnew/4d90f70258d54460be69904670ba175a.htm
  - http://www.moe.gov.cn/jyb_xwfb/s6192/s133/s146/202306/t20230609_1063563.html
