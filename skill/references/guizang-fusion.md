## 1. 两种风格（照搬）

- **风格 A · 电子杂志 × 电子墨水（默认）**：衬线 + 流体背景 + 暖色；
  WebGL 流体 / 等高线 / 色散背景（hero 页可见）。
- **风格 B · 瑞士国际主义**：无衬线 + 网格点阵 + 单一高亮色
  （IKB / 柠檬黄 / 柠檬绿 / 安全橙）。

## 2. 负向约束（照搬，违反任何一条风格就垮）

### 通用
- 一份 deck 只用一套主题，不要中途换色；不允许混搭
  （例如 ink 取墨水经典、paper 取沙丘）——会彻底违和。
- 不要把用户给的 hex 值直接写进页面——走受约束的品牌色脚本
  （`scripts/gz-theme.mjs brand "#4D6BFE" --family magazine`，瑞士风用
  `--family swiss`）；脚本判定不达标时回到 5 套预设让用户选。
- 不要直接修改模板里的颜色——所有颜色都走语义变量，
  换主题只改 `<html>` 的 `data-theme` 一处；`GZ:TOKENS` 区块不要改。
- 底色走命名纸色 token（墨水经典 / 靛蓝瓷 / 森林墨 / 牛皮纸 / 沙丘），
  不直接写纯白/纯黑。
- 模板是唯一的类名来源——不要发明新类名；缺失的类在模板 `<style>` 里补，
  不要在每个 slide 里 inline 重写。
- 不要从零写 slide：用登记好的布局骨架（归藏有 10 种通用布局、
  瑞士风 22 个登记版式），按骨架填内容。
- SVG 只负责几何图形，不要在 SVG 里写文字标签，标签改用 HTML 网格/卡片/caption。
- 图片只裁底部，保证顶部和左右完整；图片内部不要自带页眉、页脚、页码、
  logo、主标题、装饰边框或署名。
- 文字压图前先做 quiet-zone 判断：图里至少要有约 30% 低细节区域承载文字；
  不通过就换图、换裁切或改成图文分栏；只在必要时加局部 tint，
  不要整页套黑色/白色遮罩。
- 标题挤占空间时先压缩标题文案、再降字号；不要靠把下方内容推到底来硬塞。
- 内容放不下时先删减文案、拆成两页、换更适合的版式，
  不要把字号压到 10/11/12/13px（中文 deck 尤其不要）。
- 溢出/空白先量后改：1–40px 只微调（上移内容组或收紧一个 gap/padding），
  不要删内容。

### 风格 A · 电子杂志风（5 轮迭代总结）
1. 克制优于炫技——WebGL 背景只在 hero 页透出，普通页几乎看不见
2. 结构优于装饰——不用阴影、不用浮动卡片、不用 padding box，
   一切信息靠大字号 + 字体对比 + 网格留白
3. 内容层级由字号和字体共同定义——最大衬线 = 主标题，中衬线 = 副标，
   大非衬线 = lead，小非衬线 = body，等宽 = 元数据
4. 图片是第一公民——图片只裁底部；网格用固定高度，不要用 aspect-ratio 撑
5. 节奏靠 hero 页——hero 和 non-hero 交替，才不累眼睛
6. 术语统一——不要中英混合翻译

### 风格 B · 瑞士国际主义风
1. 单一锚点色——一份 deck 只用一个 accent，不允许多色高亮拼贴
2. 极致字号对比——主标题与正文比例 ≥ 8:1，KPI 必须是"Data Hero"
   （屏幕宽度的 18–22%）
3. 无衬线只此一家——Inter / Helvetica / Noto Sans SC，任何衬线都是错的
4. 直角纯色——不允许渐变 / 阴影 / 圆角（rule 横线除外）
5. 网格至上——所有元素吸附到 12-col grid，左对齐 + 大幅留白做非对称美学
6. Hairline 是手术刀——1px 的极细分割线就够，不要加粗、不要加阴影
7. 点阵装饰只在 hero 页透出——正文页保持纯净底色

## 3. 主题系统（照搬）

- 5 套预设：墨水经典 `ink-classic`（默认）、靛蓝瓷 `indigo-porcelain`、
  森林墨 `forest-ink`、牛皮纸 `kraft-paper`、沙丘 `dune`。
- 换主题只改 `<html>` 的 `data-theme`，其余颜色全部走语义变量。
- light / dark 主题交替使用，每 2–3 页切换一次，避免连续超过 3 页同色；
  每页 `<section>` 必须带 `light` / `dark` / `hero light` / `hero dark` 之一。

## 4. WebGL 流体背景（照搬参数）

- 只在 hero 页透出；dark hero 遮罩 12–15%，light hero 遮罩 16–20%。
- 翻页时 WebGL 背景在两个 shader 之间渐变过渡。
- 保留低功耗快捷键：按 `B` 切换 `body.low-power`，停止 WebGL/ASCII canvas
  的 RAF 循环和 Motion 入场动画，当前页内容直接 reveal 到静态最终态；
  刷新后通过 `localStorage` 保持选择。
- 本 skill 的改编：`assets/template.html` 已按此加了 `B` 键静态模式
  （停止动画、直接显示终态）；WebGL 流体背景本身是可选模块，
  单文件模板默认用 CSS 网格+辉光，不内嵌 WebGL shader，以保轻量。

## 5. 工作流（照搬）

1. 启动前检查更新（本 skill 本地版跳过此步，不自动更新）
2. 需求澄清：7 问对齐（主题、用途、风格、页数、图片、截图、配图），
   不要基于猜测就开始写 slide
3. 拷贝模板 → 改 `data-theme` → 填占位符
4. 同步生成演讲备注：每页 `<section>` 写唯一且稳定的 `data-slide-id`，
   备注按页面 ID 存储，不要用数组下标或页码做键（否则重排后备注串页）
5. 对照检查清单自检：先量后改；截图前等入场动效稳定约 1–2 秒，
   不要把动画中间态当成版式问题
6. 本地预览 → 迭代
