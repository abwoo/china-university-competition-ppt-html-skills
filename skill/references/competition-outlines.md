# 比赛 PPT 大纲

页数是硬约束。路演短版与网评长版是**两份材料**，不要把长版直接压缩成短版。

## 1. 互联网+路演短版：15–20 页（现场 5–8 分钟）

| 页 | 内容 | 要点 |
|---|---|---|
| 1 | 封面 | 项目名 + 一句话价值主张；不要写"商业计划书" |
| 2 | 痛点 | 1 个核心痛点 + 真实场景 + 数据；不要堆背景 |
| 3 | 痛点佐证 | 用户原话 / 现场照片 / 数据图，二选一即可 |
| 4 | 解决方案总览 | 产品示意图或流程图；核心功能 ≤3 个 |
| 5 | 产品演示 | DEMO 截图或动图；一页只讲一个核心操作 |
| 6 | 核心技术 1 | 技术原理图 + 关键指标（有来源） |
| 7 | 核心技术 2（如有） | 同上；没有就并入第 6 页，不要硬凑 |
| 8 | 市场 | 只讲能吃掉的细分市场：规模 + 增速 + 可视化，不要画大饼 |
| 9 | 商业模式 | 谁付钱、怎么收、成本结构；画模式图 |
| 10 | 竞品对比 | 一张表，3–5 个对手，突出 1–2 个差异点 |
| 11 | 运营/获客 | 渠道 + 转化数据（真实的，没有就写"待验证"） |
| 12 | 团队 | 为什么非你们不可：技术 + 运营 + 市场互补，不要贴简历 |
| 13 | 财务 | 收入/成本/利润趋势图（真实数据或明确标注预测） |
| 14 | 融资需求 | 要多少钱、花在哪（分项）、出让比例 |
| 15 | 规划 | 12–18 个月里程碑，时间线形式 |
| 16 | 封底 | 一句话收尾 + 联系方式（项目名/负责人/电话/微信） |

超过 16 页时，优先加"应用案例"或"社会价值"各 1 页，上限 20 页。

## 2. 互联网+国赛网评长版：30–45 页

在短版基础上加（每项独立成页，不要并页）：

- 政策背景（1–2 页）：相关政策原文要点 + 与项目的对应关系
- 行业现状（1–2 页）：产业链图 + 规模数据（带来源）
- 研发历程（1 页）：时间线，立项 → 原型 → 迭代 → 落地
- 核心技术：每项技术独立 1–2 页（原理图 + 参数对比表）
- 子系统/母系统（1–2 页）：系统架构图
- 衍生技术/场景（1 页）
- 技术参数对比（1 页）：与国内外同类产品的参数表
- 专利壁垒（1 页）：专利清单（真实的；申请中要注明状态）
- 荣誉（1 页）
- 应用案例：每案例 1 页（场景 + 数据 + 客户反馈）
- 应用场景（1 页）
- 竞品（1–2 页）：对比表 + 定位图
- 客群/商业模式（1–2 页）
- 行业认可（1 页）
- 媒体报道（1 页）
- 领导关怀（可选，1 页；没有就不要编）
- 个人成长（1 页）
- 团队（1–2 页）
- 产教融合（1 页）
- 社会价值（1–2 页）
- 财务（2–3 页）
- 未来规划（1–2 页）
- 致谢（1 页）

原则：信息密度高、论证充分，不要怕页数多；但每页仍只讲一个观点。

## 3. 挑战杯合规版：≤20 页，8 部分

顺序与页数上限**不可调整**（按官方统一模板要求）：

| 部分 | 页数上限 | 内容 |
|---|---|---|
| 1 痛点/问题 | ≤2 | 真实问题 + 数据 |
| 2 项目概述 | ≤2 | 项目名、定位、一句话价值 |
| 3 核心技术 | ≤4 | 原理 + 指标 + 对比 |
| 4 商业模式 | ≤3 | 付费方、收入、成本 |
| 5 应用场景/落地 | ≤4 | 场景 + 落地进展 |
| 6 团队 | （含在 8 部分内） | 分工与互补性 |
| 7 财务/融资 | （含在 8 部分内） | 真实数据优先 |
| 8 社会价值 | ≤1 | 社会效益，不要拔高 |

同时遵守：16:9；转 PDF 后 20 页以内，超页只审前 20 页；
**不追求过度视觉化、艺术化效果，不随意使用复杂动效、3D 渲染、特效字体**。
因此挑战杯一律用合规克制版：深色科技造型只留在封面/章节/架构页，
内容页用静态深底 + 高对比文字。

## 4. 黑客松：6 页（创意轮）/ 8 页（决赛）

创意轮 6 页：标题、问题、方案、如何工作、技术栈/可行性、影响。
决赛 8 页：问题、做了什么、现场 demo、如何工作、结果（准确率/速度/用户数）、
下一步、致谢（留 GitHub / demo 链接）。
demo 尽量放第 3–4 页；一页一个观点；3–5 分钟讲完。
