# HUD 配方（22-hud 搬运改编）

来源：Vincentwei1021/mg-styles-15，`prompts/22-hud.md`（MIT，
Copyright (c) 2026 Vincentwei1021）。
原作是 10 秒赛博朋克 HUD / FUI 短片配方（原片"隼眼-9 · 目标锁定"，
1920×1080，30fps，AI 评审终评 7.93/10）。
本文件把它的配方改写成 tech-style 可复用的 HUD 模块清单与参数，
配色接入本 skill 的蓝紫+黄母版；青色线框保留为可选模块。
完整出处与许可见 `references/attribution.md`。

## 1. 风格一句话

深青黑底、青色 `#00E5FF` 线框 + 橙/红 `#FF6A00` 告警（本 skill 中告警色
可用标题黄 `#FFB829` 替代），六边形网格、同心旋转环+刻度、雷达扫描+
闪烁目标点、等宽小字数据流、打字机文字、辉光+扫描线+轻微色差、目标锁定框。

## 2. Signature features（必须有的特征，缺一个就不像）

1. 青色/橙色霓虹线框
2. 目标锁定框与十字准星
3. 雷达/环形扫描 loop
4. 等宽小字数据流与打字机文字
5. 六边形网格与辉光

## 3. 关键技法（参数照搬，只做最小适配）

### 线框生长
- SVG `stroke-dasharray` / `stroke-dashoffset` 描边动画；
- 元素按层级错帧展开，先画线、后出数据（与 fireworks 的 settled-flow 一致）。

### 环形雷达
- `conic-gradient` 扫描扇区旋转 loop + 目标点闪烁；
- CSS 参考：
```css
.radar {
  background: conic-gradient(from 0deg, rgba(34, 211, 238, 0.5), transparent 25%);
  animation: spin 4s linear infinite;
  border-radius: 50%;
}
@keyframes spin { to { transform: rotate(360deg); } }
```

### 数字滚动
- 随机数快速跳变 3–5 帧后落定真实值；
- 文字打字机 + 光标闪烁。

### 目标锁定框
- 四角括号从大到小收缩吸附目标：`scale(1.4) → scale(1.0)`，快出缓入；
- 锁定瞬间整体翻转为告警色（橙/黄），显示 `TARGET LOCKED / 目标锁定` 与坐标。

### 全局质感
- 辉光（glow）+ 轻微色差（chromatic aberration）+ 扫描线叠加，统一质感；
- 克制使用微故障（micro-glitch），不要满屏闪。

## 4. 节拍表（10 秒短片的原始结构，改编成演示时序）

| 时间 | 画面 |
|---|---|
| 0–0.5s | 钩子：第一帧就必须有内容，不许黑场超过 0.3 秒 |
| 0.5–4s | 线框按层级生长，数据活起来 |
| 4–7s | 找到目标，锁定框收缩，hero 时刻（全片 60–75% 处） |
| 7–9s | 翻转为告警色，显示锁定信息与坐标 |
| 9–10s | 定格终帧，保持 0.8–1.2 秒，留有微动效 |

做 HTML 演示时把同一张表换成：节点依次出现 → 连线流动 → 核心节点锁定发光 → 数字落定 → 终态停留。

## 5. 工作法（照搬）

1. **先写一句话创意与节拍表**：钩子、升级、hero 时刻、定格终帧；每个 signature
   特征对应到一个时刻；画面与声音共用同一张节拍表。
2. **先出关键帧静帧再做动效**：在 6–10 个关键时间点渲染静帧并逐张看，
   每张都应达到海报水准（构图、层级、留白、字距、行高、5% 安全边距），
   不满意就改，不要带着"模板感"进入动效。
3. **动效**：低分辨率预览，逐帧检查最快动作的间距、缓动、弧线、重叠、
   预备与跟随、运动模糊；不留无意义的空段；能量跟随音乐/节拍。
4. **声音**：按节拍表配乐与音效，视觉落点对齐音频起始点；成品响度 -14 LUFS，
   真峰值 ≤ -1 dBTP（只在出视频时适用）。
5. **终检**：时长、分辨率、帧率、音频、黑帧、缺字、边缘裁切、细线闪烁、
   渐变断层，逐项检查；再写一段诚实自评（最强、最弱、有更多时间会改什么）。

## 6. 确定性渲染（照搬）

每一帧必须是时间 t 的纯函数；只用种子随机；物理与粒子预计算或用闭式解；
不用真实时钟、不用状态触发的 CSS 过渡。
可靠路线：网页按任意时间 t 画出画面，无头浏览器逐帧截图，ffmpeg 编码
（与 HyperFrames 的确定性逐帧渲染是同一思路）。

## 7. 在 tech-style 里怎么用

- 每页最多选 **1 个** HUD 模块（雷达、扫描线、打字机、锁定框、六边形网格五选一），
  与 style-tokens.md 的反 AI 味规则一致；
- 封面/章节页：雷达或锁定框其一；
- 架构/流程页：锁定框标出 kernel 节点；
- 内容页：不用 HUD 模块，只留等宽小字页脚。
