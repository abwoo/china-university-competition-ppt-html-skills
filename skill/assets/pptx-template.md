# PPTX 母版规格（tech-style）

本文件是 agent 用 python-pptx / PptxGenJS 生成原生 PPTX 时的母版规格。
融合了 PPT Master 的 SVG→DrawingML 路线（见 `references/pptx-fusion.md`）与
Anthropic pptx 的设计思路（见 `references/anthropic-pptx-fusion.md`）。
注意：PPTX 原生对象无法承载辉光、网格动画、粒子、流动线，
复杂图一律用 HTML 模板截图成 PNG 贴入。

## 画布

- 尺寸：16:9，`10 × 5.625 英寸`（`prs.slide_width = Inches(10)`）
- 版式：空白版式（`slide_layouts[6]`），全部元素用代码定位，不用默认占位符

## 颜色（与 HTML token 同源，去掉 alpha）

| 用途 | 颜色 |
|---|---|
| 舞台底 | `#06070A` |
| 舞台底 2 | `#0A0A14` |
| 卡片底 | `#12122B`（实色近似 `rgba(123,97,255,0.06)` 叠加后的效果） |
| 卡片描边 | `#A78BFA`（只用于核心卡片；普通卡片用 `#3D3A6B`） |
| 节点主色 | `#7B61FF` |
| 流动线 | `#22D3EE` |
| 标题黄 | `#FFB829` |
| 正文 | `#EDEFF7` |
| 次要文字 | `#9AA3B2` |

一主色（蓝紫）+ 一强调色（黄），不要第三主色。

## 字体

- 中文标题：思源黑体 Bold / 微软雅黑 Bold / 等线 Bold；中文正文：思源黑体 Regular / 微软雅黑 Regular / 等线
- 英文/数字：Arial / Inter / Montserrat；封面大数字可用 Arial Black；数字 callout 60–72pt
- 数字/标签/序号：等宽字体（Consolas / JetBrains Mono）
- 标题 36–44pt，加粗；章节头 20–24pt；正文 14–16pt（比赛 PPT ≥18pt）；注释/来源 10–12pt（`#9AA3B2`）
- **版权**：思源黑体免费商用（SIL OFL 1.1），可嵌入；微软雅黑不是免费商用（版权归方正，仅限 Windows 系统内个人使用）
- **字体回退**：首选思源黑体（Mac/Windows 都原生支持）；交付前嵌入字体（选"嵌入所有字符"；macOS 版 PowerPoint 不支持嵌入，改出 PDF）；随身带 PDF 备份；在答辩电脑上打开测试过
- python-pptx 设字体时同时写 latin 与 east asian 两个 typeface（见 `scripts/make_pptx.py` 的 `set_font`），否则中文在 PowerPoint 里可能回退到默认字体

## 结构："三明治"（Anthropic pptx，照搬）

深色底做标题页 + 结尾页，浅色底做内容页；或者全程深色走高级感——二选一，
定下来就贯彻到底。本 skill 默认全程深色（科技风），合规克制版用三明治
（内容页浅色高对比）。

## 避坑（Anthropic pptx，照搬）

- 标题下不加强调线；不加装饰性色条/强调条（通栏条、一侧竖条、卡片边缘细条、单边边框）
- 不要默认用奶油/米色底；不要重复同一个版式；不要居中正文（只居中标题）
- 每页必须有视觉元素（图片、图表、图标或形状），纯文字页会被忘掉
- 页边距最小 0.5 英寸，内容块之间 0.3–0.5 英寸，间距全 deck 一致

## 母版

### 封面
- 全页深底 + 网格 PNG（HTML 模板截图，铺满，透明度低）或纯色底
- 左上角小字 kicker（等宽，`#22D3EE`，字母间距大，如 `INTERNET+ // 2026`）
- 中央黄色大标题（36–44pt），副标题白色 20pt
- 底部一行：项目名 / 团队名 / 日期（14pt，`#9AA3B2`）

### 章节页
- 深底 + 章节序号（等宽大字，`#22D3EE`）+ 留白分隔，不加左侧装饰竖线
  （Anthropic 禁装饰性色条/单边边框，见上文"避坑"）
- 章节标题黄色 32pt，一句话说明白色 18pt

### 内容页
- 深底（纯色，不要网格图，避免干扰阅读）
- 顶部：小节标题白色 28pt，标题下不加强调线、不加黄色下划线
  （Anthropic 禁标题下强调线，用留白分隔，见上文"避坑"）
- 主体：卡片（`#12122B` 底 + `#3D3A6B` 描边）或图表；每页一个观点
- 页脚：页码 + 项目名（12pt，`#9AA3B2`），右下角

### 结尾页
- 同封面结构，标题换成一句话收尾（如"谢谢，欢迎提问"）
- 联系方式居中：负责人 / 电话 / 微信 / 邮箱

## 图表

- 柱状/折线/饼图：用原生图表（python-pptx `add_chart`），系列色只用蓝紫/青/黄
- 流程/架构图：HTML 模板截图 PNG 贴入，宽度 ≤9 英寸，居中
- 对比表：原生表格，表头 `#7B61FF` 底白字，胜出单元格用黄色字标出

## 演讲者备注

每页备注写 60–120 字的讲稿（中文口语），不要把讲稿塞进正文。

## 评审 / 投资人喜欢的版式（直接抄来的，2026-11-10）

> 只抄结构、配色、字号、版式，不抄别人的项目内容、数字、文字。
> 完整 token 与出处见 `references/style-tokens.md` 第 12、13 节，
> 出处总表见 `references/attribution.md` 第 9 节。

### 投资人版 10 页顺序（Sequoia 骨架，顺序本身就是论证）
公司宗旨 → 问题 → 解决方案 → 为什么是现在 → 市场规模 →
竞争 → 产品 → 商业模式 → 团队 → 财务。
10–12 页硬上限；投资人平均只看约 3 分 44 秒（2023 年约 2 分 24 秒），
财务页（23.2 秒）与团队页（22.8 秒）看得最久，成功 deck 的
"为什么是现在"页多看 65%、竞争页多看 88%；只有 58% 的 deck
会被看到最后一页。**traction 放前 3 页**（多 20% 浏览量），
关键结论不要只放在结尾页。Guy Kawasaki 10/20/30：
10 页、20 分钟、字号 ≥30pt。

### 每页写法（抄来的硬规则）
- 每页标题必须是**一句话结论**，不是栏目名："市场分析""团队介绍"
  改写成带真数字的判断句；每页（不含标题）≤25 字/30 个字；一页一个观点。
- 数据页固定写法：左上角一句话"这一页想证明什么"，右下角
  "所以这意味着什么"；重点数字放大、坐标轴灰色。
- 竞争页只列 3 个真正重要的维度，并承认对手在某些地方做得不错，
  不要 12 维全勾表。
- 结尾页不要只写"谢谢/Q&A"，写融多少钱、干什么、联系方式/二维码。
- 每页右下角浅灰小页码 + 左上角 Section 标签。
- 动效克制：数据逐条展示、图片渐入可以，花哨页面切换不要；
  整场动画类型 ≤3 种。
- 文字零防御性：观点直接前置，禁"可能在一定程度上或许"、
  "我们并不声称""需要注意的是"；详见
  `references/anti-defensive-writing.md`。

### 直接抄来的 PPT 配色（与 HTML token 同源，另加两套）
- **ppt-agent dark_tech**：底 `#050b1f` → `#0a1f3d`，卡片
  `rgba(34,211,238,0.08)` → `rgba(99,102,241,0.04)`，
  强调 `#22D3EE/#3B82F6/#6366f1/#FDE047`，80px 点阵网格；
  标题 Inter Tight（中文：思源黑体 Bold，字距收紧）、
  等宽 JetBrains Mono。深色科技路演首选。
- **路演安全版（白底黑字，投资人最不会错）**：底 `#FFFFFF`、
  正文 `#111111`、单个高饱和主色 `#2563EB`。
- **Wonderslide Clean Tech**：浅灰底 `#F5F6F8`、炭灰字 `#1F242B`、
  卡片 `#E3E8EF`、亮青点缀 `#00C2FF`（只用在编号、流程步骤）。
- **Wonderslide Nocturne**：午夜藏青 `#0B1220`、卡片
  `rgba(255,255,255,0.04)`、高光 `#7B61FF`，适合文字多的进展汇报。
- **华工官方模板结构**（学校官网公开 .ppt，3 页）：封面白底居中大标题
  + 右上学校 logo + 下方组别/负责人；内容 8 部分：市场调研与痛点、
  技术优势与壁垒、应用案例、团队/组织架构、技术与商业支持、
  商业营销与财务分析（含财务预测）、风险控制与投融资需求、社会效益。
  抄结构，不抄它的白底素版视觉。
- **codex-ppt 工作法**：先出一样张、用户点头后再做全套；
  一套视觉系统走到底、每页按内容角色换版式，不要每页长得一样；
  科研答辩风、麦肯锡风格、数据仪表盘风三套可直接点名用。
